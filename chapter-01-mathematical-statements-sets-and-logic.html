1. Mathematical statements, sets, and logic

A specification says that every input has an acceptable output. A programmer replaces it with the stronger requirement that one output work for every input. The replacement looks harmless in English, yet it can turn a solvable problem into an impossible one. Algebra begins with this discipline: specify the objects, the permitted operations, and the exact statement before trying to prove it.

The course introduction and official lessons 1–3 provide the source sequence. The examples, formal arguments, program, and exercises are independently authored. Timestamp links locate related discussion. The introduction previews later courses on groups, rings, modules, and quantum algorithms; those later courses are outside this edition.

1.1 Objects, properties, and proofs Lesson 1 · 00:42

Suppose an input can be either the symbol $0$ or the symbol $1$, and an acceptable output must be different from the input. Input $0$ permits output $1$; input $1$ permits output $0$. Every input has an output, but neither output works for both inputs. No calculation is difficult here. The difficulty is keeping the two claims distinct.

A mathematical model separates the objects under discussion from assertions about them. Here the objects are the two input symbols and two output symbols, and the assertion concerns which pairs are acceptable. Later algebraic problems retain the same discipline: specify which objects are fixed, which may vary, and which choices may depend on earlier choices.

A definition fixes what a term means. A proposition asserts something that has a truth value in the specified setting. A proof derives a proposition from definitions and stated assumptions by accepted rules of reasoning. A definition can be inconvenient, but it is not established by testing examples. A proposition can be false, even if many examples support it.

For example, define an integer to be even when it equals $2k$ for some integer $k$. This definition makes $14$ even because $14=2\cdot7$. The assertion that the sum of two even integers is even needs an argument: writing the two integers as $2a$ and $2b$ gives a sum $2(a+b)$, and $a+b$ is again an integer. The definition supplies the form that the proof must produce.

Throughout the book, $\mathbb N=\{1,2,3,\ldots\}$ denotes the positive natural numbers, $\mathbb N_0=\{0,1,2,\ldots\}$ includes zero, and $\mathbb Z$ denotes the integers. We initially use familiar integer arithmetic and later examine its axiomatic structure. The distinction prevents a circular claim that every school arithmetic fact has already been reconstructed from set theory.

Computations can reveal a conjecture or expose a false statement. Their evidential scope depends on the domain. Checking all four input/output pairs settles our two-symbol specification. Checking a million integers does not settle a claim about every integer. A universal proof explains why an unexamined case must also work.

1.2 Sets, membership, and equality Lesson 2 · 09:10

A set is treated here as a collection whose membership is specified. Its objects are its elements. The expression $x\in A$ means that $x$ is an element of the set $A$, and $x\notin A$ denies that membership. This is an elementary working language for sets, not an axiomatization of every possible collection.

A finite set can be described by listing its elements inside braces. For our specification, let $X:=\{0,1\}$ be the input set and $Y:=\{0,1\}$ the output set. The symbol $:=$ introduces a definition. The equality $X=Y$ then states that these two names denote the same set. Their different roles do not require different underlying elements.

Sets disregard order and repetition: $\{0,1,1\}=\{1,0\}$. This follows from the extensionality principle: two sets are equal precisely when they have the same elements. An ordered list has more information than a set. Replacing a list of repeated observations by a set discards its order and multiplicities; that replacement is a mathematical modeling decision.

Definition 1.1. A set $A$ is a subset of $B$, written $A\subseteq B$, when every element of $A$ is an element of $B$. It is a proper subset, written $A\subsetneq B$, when additionally $A\ne B$.

The empty set, denoted $\varnothing$, has no elements. A singleton is a set with exactly one element; for example, $\{\varnothing\}$ has the empty set as its one element. Consequently $\varnothing\ne\{\varnothing\}$. Whether $\varnothing$ is an element of some other set depends on its listed members. Whether it is a subset has a uniform answer, which the logic of implication will explain.

Membership and inclusion have different inputs. Take $S:=\{\varnothing\}$. Then $\varnothing\in S$ is true because the empty set is the one listed element. Also $\{\varnothing\}\subseteq S$ is true because every element of this singleton belongs to $S$. But $\{\varnothing\}\in S$ is false: the sole element of $S$ is $\varnothing$, which differs from the nonempty set $\{\varnothing\}$. This example does not depend on any particular construction of numbers as sets.

Proposition 1.2, proved here. For any sets $A$ and $B$, $A=B$ if and only if both $A\subseteq B$ and $B\subseteq A$.

If $A=B$, membership in either set is membership in the other, giving both inclusions. Conversely, suppose both inclusions hold. Any element of $A$ belongs to $B$ by the first inclusion; any element of $B$ belongs to $A$ by the second. The sets therefore have exactly the same elements, so extensionality gives $A=B$. ∎

This result turns equality into two directed tasks. To disprove $A\subseteq B$, it is enough to find one element of $A$ outside $B$. For example, $\{0,1\}\not\subseteq\{1,2\}$ because $0$ is missing from the second set. An element present in both sets cannot establish an inclusion.

Hammack, Book of Proof, §§1.1 and 1.3, printed pp. 3–4 and 12, develops these distinctions. The two-symbol specification above uses them to separate the domain of a problem from claims about that domain.

1.3 Properties specify subsets Lesson 2 · 14:55

Listing elements is unsuitable when the set is large or infinite. A property, or predicate, on a specified set $S$ is an expression $P(x)$ that can be evaluated as true or false once an element of $S$ is assigned to $x$. An occurrence of a variable is free when it is not within the scope of a quantifier binding that occurrence. Assigning a value evaluates a free variable; it does not change that occurrence into a bound one. The expression “$x$ is even” has no fixed truth value without an assigned integer or a quantifier.

The notation $\{x\in S:P(x)\}$ denotes the subset of $S$ consisting of elements for which $P(x)$ is true. The colon means “such that.” Thus $E:=\{x\in\mathbb Z:x=2k\text{ for some }k\in\mathbb Z\}$ is the set of even integers. The ambient domain matters: solutions of $x^2=9$ in $\mathbb N$ form $\{3\}$, while solutions in $\mathbb Z$ form $\{-3,3\}$.

Set-builder notation filters a specified set. It does not grant permission to form the set of absolutely everything satisfying an arbitrary sentence. Unrestricted collection formation leads to contradictions discussed in Chapter 6. For elementary algebra, naming the ambient set makes most constructions precise without beginning with a full theory of mathematical foundations.

1.4 Compound statements and their truth values Lesson 3 · 02:16

We use classical two-valued logic. A proposition is either true or false in its specified interpretation. This convention concerns the meaning of a statement, not whether a particular person knows its truth value. An unproved conjecture is not assigned a third truth value called “unknown.”

Let $p$ and $q$ denote propositions. Their negation $\neg p$ is true precisely when $p$ is false. Their conjunction $p\land q$ is true when both are true. Their disjunction $p\lor q$ is true when at least one is true, including the case that both are true. “Or” has this inclusive meaning unless an exclusive condition is explicitly added.

A truth table lists every assignment of truth values to the constituent propositions, then evaluates a compound expression. A tautology is true under every such assignment. For instance $p\lor\neg p$ is a tautology: if $p$ is true its first part is true, and if $p$ is false its second part is true. The truth of a tautology follows from its logical form.

An arithmetic fact need not be a tautology in its displayed propositional form. The statement “$2$ is even” is true because of the arithmetic interpretation and definition of evenness. Treating that entire statement as a single propositional variable does not make the variable true under every possible truth assignment. Logical validity and truth in a particular mathematical structure are different assertions.

1.5 Implication and empty-domain reasoning Lesson 3 · 05:51

The implication $p\Rightarrow q$, read “if $p$, then $q$,” is false only when $p$ is true and $q$ is false. Here $p$ is the antecedent and $q$ the consequent. Equivalently, $p\Rightarrow q$ has the truth value of $\neg p\lor q$: when $p$ is false the first part is true, and when $p$ is true the second part has exactly the value of $q$. Table 1.1 makes both cases explicit.

The implication makes no demand when its antecedent is false. For a fixed integer $n$, consider “if $n=2k$ for some integer $k$, then $n^2$ is even.” At $n=3$, the antecedent fails, so the conditional is true irrespective of the consequent. This vacuous truth is needed to express a rule that constrains even integers without asserting that every integer is even.

Material implication is a truth-functional connective, not a causal claim. For example, “$2$ is even” and “$3$ is odd” are both true, so the implication from the first to the second is true. It asserts no mechanism by which the first fact causes the second. A proof of a general mathematical implication must still justify why the conclusion follows for every permitted object.

The converse is $q\Rightarrow p$. It is a separate assertion. Divisibility by $4$ implies evenness: $n=4k$ gives $n=2(2k)$. The converse fails at $n=2$. The biconditional $p\Leftrightarrow q$, read “if and only if,” requires both implications. One direction cannot establish it.

Proposition 1.3, proved here. The empty set is a subset of every set $A$.

To fail inclusion, an element would have to belong to $\varnothing$ and fail membership in $A$. There is no element of $\varnothing$. Equivalently, every conditional $x\in\varnothing\Rightarrow x\in A$ has a false antecedent, so every required conditional is true. Thus $\varnothing\subseteq A$. ∎

This proof does not establish $\varnothing\in A$. For $A=\{1\}$, empty-set membership is false even though empty-set inclusion is true. The universal inclusion concerns possible counterexamples to a rule, while membership concerns an actual element. Hammack §2.3, printed pp. 42–43, gives the same truth-table convention for conditional statements.

1.6 Quantifiers and witness dependence Lesson 3 · 17:17

Let $P(x)$ be a predicate on $S$. The universal quantifier gives the proposition $\forall x\in S,\ P(x)$: every element of $S$ satisfies the predicate. The existential quantifier gives $\exists x\in S,\ P(x)$: at least one element satisfies it. An element establishing an existential assertion is a witness. The quantifier binds the displayed variable.

For our sets $X=Y=\{0,1\}$, let $R(x,y)$ mean $x\ne y$. The statement

$$\forall x\in X\ \exists y\in Y,\ R(x,y)$$

is true. If $x=0$, choose $y=1$; if $x=1$, choose $y=0$. The witness may depend on the input already chosen. Reversing the quantifiers gives

$$\exists y\in Y\ \forall x\in X,\ R(x,y).$$

This is false. Choosing $y=0$ fails at $x=0$, and choosing $y=1$ fails at $x=1$. Both possible witnesses have been eliminated. A common witness would imply a witness for each input, but witnesses chosen separately need not combine into a common one.

The issue is dependence, not the visual order of symbols alone. Two universal quantifiers over fixed sets can be exchanged because both require every pair. Two existential quantifiers over fixed sets can also be exchanged because both ask for one successful pair. Mixing a universal and an existential quantifier changes what a witness is allowed to depend on. In special predicates the two mixed orders may happen to have the same truth value; they are not equivalent in general.

For an empty domain $S$, $\forall x\in S,P(x)$ is true because there is no counterexample, while $\exists x\in S,P(x)$ is false because no witness exists. A proof using “choose an element of $S$” must first know that $S$ is nonempty. This small condition will recur in basis arguments and inverse constructions.

1.7 Negating an exact specification Lesson 3 · 21:03

A universal statement fails precisely when at least one counterexample exists. An existential statement fails precisely when every candidate fails. Therefore the quantifier negation rules are

$$\neg(\forall x\in S,P(x))\ \Longleftrightarrow\ \exists x\in S,\neg P(x),\qquad \neg(\exists x\in S,P(x))\ \Longleftrightarrow\ \forall x\in S,\neg P(x).$$

The preceding sentences are proofs from the meanings of the quantifiers; they remain valid for empty sets. At the propositional level, a conjunction fails if at least one component fails, while a disjunction fails only if both fail. These are De Morgan's laws: $\neg(p\land q)\Leftrightarrow(\neg p\lor\neg q)$ and $\neg(p\lor q)\Leftrightarrow(\neg p\land\neg q)$.

Classical double negation gives $\neg\neg p\Leftrightarrow p$. If $p$ is true, its negation is false and the second negation is true. If $p$ is false, the two negations instead return false. Thus the original and double-negated statements agree in both cases. This principle will justify the conclusion of a proof by contradiction.

Negate the original solvability claim one layer at a time. Applying the first quantifier rule and then the second gives

$$\neg\bigl(\forall x\in X\ \exists y\in Y,R(x,y)\bigr) \ \Longleftrightarrow\ \exists x\in X\ \forall y\in Y,\neg R(x,y).$$

The negation says that some input has no acceptable output. It does not say that every input fails. In contrast, the negation of a common witness is $\forall y\in Y\ \exists x\in X,\neg R(x,y)$: each proposed common output has a counterexample input, which may depend on that output. Our two-symbol problem satisfies this latter failure condition.

For a conditional specification $\forall x\in S,(P(x)\Rightarrow Q(x))$, negation produces $\exists x\in S,(P(x)\land\neg Q(x))$. A failed example must satisfy the hypothesis and violate the conclusion. Testing an input outside the hypothesis cannot refute the rule. Hammack §2.10, printed p. 60, records the quantifier rules; the dependency example here shows why retaining their order matters.

1.8 An exhaustive finite specification check

The following standard-library program enumerates truth assignments and all binary acceptability tables on two inputs and two outputs. A table is stored as two rows, each containing two Boolean values. It prints how many tables allow an output for each input and how many admit a common output. It performs no file or network operations. The fixed enumeration is exhaustive for this two-element model; it makes no claim about arbitrary infinite domains.

from itertools import product

truths = list(product([True, False], repeat=2))
implication = [(not p) or q for p, q in truths]
assert implication == [True, False, True, True]
per_input = common = 0
for entries in product([False, True], repeat=4):
    rows = [entries[:2], entries[2:]]
    separate = all(any(row) for row in rows)
    shared = any(all(row[j] for row in rows) for j in range(2))
    assert not shared or separate
    per_input += separate
    common += shared
print("implication:", implication)
print("per-input tables:", per_input)
print("common-output tables:", common)

implication: [True, False, True, True]
per-input tables: 9
common-output tables: 7

The two counts differ because the two permutation tables permit only input-dependent witnesses. The program's assertion checks that every common-output table also has a witness in each row. The general logical implication was established independently: reuse the common witness for each input. Exhaustive enumeration checks that the implementation matches this argument.

1.9 Problems and worked solutions

Problem 1 · Membership versus inclusion

Let $A=\{\varnothing,\{\varnothing\}\}$. Determine the truth of $\varnothing\in A$, $\varnothing\subseteq A$, $\{\varnothing\}\in A$, $\{\varnothing\}\subseteq A$, and $\{\{\varnothing\}\}\subseteq A$. Explain each decision from the definitions.

Solution

All five statements are true. The empty set is explicitly the first listed element, and it is a subset of every set. The singleton containing the empty set is explicitly the second listed element. Its sole element $\varnothing$ belongs to $A$, proving the fourth statement. The sole element of $\{\{\varnothing\}\}$ is $\{\varnothing\}$, which belongs to $A$, proving the fifth. The last two tests inspect different sole elements; their common truth value does not make membership and inclusion interchangeable.

Problem 2 · Choosing a witness

Over the integers, prove $\forall x\ \exists y,\ x+y=0$, disprove $\exists y\ \forall x,\ x+y=0$, and negate both statements.

Solution

For an arbitrary integer $x$, choose its additive inverse $y=-x$; then $x+y=0$. If a common $y$ existed, $x=0$ would force $y=0$, whereas $x=1$ would force $y=-1$, a contradiction. The negation of the first statement is $\exists x\in\mathbb Z\ \forall y\in\mathbb Z,\ x+y\ne0$. The negation of the second is $\forall y\in\mathbb Z\ \exists x\in\mathbb Z,\ x+y\ne0$. The latter is true: for a proposed $y$, choose $x=1-y$, giving $x+y=1$.

Problem 3 · Vacuity

Using the school arithmetic fact that real squares are nonnegative, determine whether $\forall x\in\mathbb R,(x^2+1=0\Rightarrow x=17)$ is true. Does this prove that $17$ solves $x^2+1=0$?

Solution

The antecedent is false for every real $x$, because $x^2+1\ge1$. Every displayed implication is therefore true, so the universal statement is true. It supplies no witness for the antecedent. In particular $17^2+1$ is positive, so $17$ is not a solution. A conditional restriction on hypothetical solutions does not assert that a solution exists.

Problem 4 · A false converse

Let $p(n)$ mean that integer $n$ is divisible by $4$, and $q(n)$ that $n$ is even. Prove $\forall n,(p(n)\Rightarrow q(n))$. Give the exact condition a counterexample to its converse must satisfy, and exhibit one.

Solution

If $p(n)$ holds, $n=4k=2(2k)$ for some integer $k$, so $q(n)$ holds. The converse is $q(n)\Rightarrow p(n)$; a counterexample must satisfy $q(n)\land\neg p(n)$. The integer $2$ is even but is not divisible by $4$. An odd integer would fail $q(n)$ and hence could not refute the converse.

Problem 5 · Empty domains

Take $X=\varnothing$ and $Y=\varnothing$. Compare $\forall x\in X\ \exists y\in Y,R(x,y)$ with $\exists y\in Y\ \forall x\in X,R(x,y)$. Which familiar implication between the two remains valid?

Solution

The first statement is true: there are no inputs at which its inner existential requirement must be met. The second is false because its outer existential quantifier has no possible witness. The implication from a common witness to a witness for each input remains valid, since its antecedent is false here. The reverse implication fails. This example shows why a proof beginning by choosing an input cannot be used without accounting for an empty input set.

Problem 6 · Explain the finite counts

Derive the program's counts of nine per-input tables and seven common-output tables without running it. Identify the two tables counted only in the first class.

Solution

Each row of a per-input table may be $(\mathrm T,\mathrm F)$, $(\mathrm F,\mathrm T)$, or $(\mathrm T,\mathrm T)$. The two independent row choices give $3\cdot3=9$ tables. For a common output, the first column may be entirely true, leaving two arbitrary entries in the other column and hence four tables. An entirely true second column also gives four. The all-true table belongs to both classes, so their union has $4+4-1=7$ tables. The remaining per-input tables are the identity and swap patterns: their rows are opposite single-true rows. Each row contains a witness, but neither column is entirely true.

Sources, boundaries, and the next question

The course introduction motivates the foundations-to-linear-algebra sequence. Lesson 1 distinguishes objects, properties, and proofs; Lesson 2 supplies membership, inclusion, equality, set descriptions, and the empty set; Lesson 3 supplies connectives, implication, quantifiers, and negation. Hammack's author-hosted Book of Proof, §§1.1, 1.3, 2.3, 2.7, and 2.10, supports the formal conventions.

The results concern ordinary classical reasoning about specified sets. They do not resolve the foundations of set theory or provide a decision algorithm for every mathematical statement. The reader can now state a specification exactly, identify the witness dependencies it permits, and write the condition that would refute it. The next chapter develops proof methods that turn those logical tasks into arguments.
