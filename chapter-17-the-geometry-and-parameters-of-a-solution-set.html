17. The geometry and parameters of a solution set

Once one solution of $Ax=b$ is known, all the others are obtained by adding solutions of $Ax=0$. The right-hand side selects a translated set; the coefficient matrix determines the directions within it. Elimination gives explicit generators for those directions and identifies the combinations of columns that can produce a permitted right-hand side.

Lesson 31 motivates null spaces, spans, rank, and the later definitions of basis and dimension. We use Chapter 15's proved uniqueness of RREF to make rank well defined immediately, and construct the null generators without assuming that pivot columns occur consecutively. Formal dimension statements follow in Chapters 19–20.

17.1 Homogeneous solutions survive addition and scaling Lesson 31 · 00:24

For $A\in F^{m\times n}$, its null space, or kernel, is $N(A)=\{x\in F^n:Ax=0\}$. It contains zero because $A0=0$. If $u,v\in N(A)$, distribution gives $A(u+v)=Au+Av=0$, so $u+v\in N(A)$. For any $c\in F$, $A(cu)=cAu=0$, so $cu\in N(A)$.

In particular negatives and differences remain inside, since $-u=(-1)u$. These properties say that $N(A)$ is a coordinate subspace: a subset of $F^n$ containing zero and closed under vector addition and scalar multiplication. Chapter 18 will put this same closure condition inside arbitrary vector spaces.

Proposition 17.1, proved here. If $Ax_0=b$, then the complete solution set of $Ax=b$ is $x_0+N(A):=\{x_0+v:v\in N(A)\}$.

For $v\in N(A)$, $A(x_0+v)=Ax_0+Av=b+0=b$, proving one inclusion. Conversely if $Ay=b$, then $A(y-x_0)=Ay-Ax_0=0$, so $v=y-x_0\in N(A)$ and $y=x_0+v$. This proves the reverse inclusion. ∎

A nonempty translate of a subspace is an affine subspace. It need not contain zero, so it need not itself be a coordinate subspace. Changing the particular solution does not change the translate: if $x_1$ is another solution, $x_1-x_0\in N(A)$, and adding this member only relabels the null vectors. If the original system is inconsistent, no particular solution exists and this formula cannot be used.

17.2 Replace a set by its finite generating list Lesson 31 · 05:18

A linear combination of a list $v_1,\ldots,v_k\in F^n$ is a vector $\sum_{j=1}^k c_jv_j$ with $c_j\in F$. Its span is the set of all such combinations. The empty list has only the empty sum, defined as zero, so its span is $\{0\}$.

A span is a coordinate subspace. Set all coefficients to zero to obtain zero. Adding combinations adds their corresponding coefficients; multiplying a combination by $c$ multiplies each coefficient by $c$. Thus both operations preserve membership. Also a subspace containing every $v_j$ contains their span, by repeated closure under addition and scaling. The span is therefore the smallest subspace containing the list.

Over $\mathbb R$, the span of one nonzero vector is a line through zero. A zero vector instead spans only a point. Two vectors span a plane only when neither is a scalar multiple of the other; otherwise the span is a line or a point. Such degeneracies matter. Over a field with $q$ elements, a nonzero vector has $q$ distinct scalar multiples, because $cv=dv$ and a nonzero coordinate force $c=d$. The same algebraic line then has finitely many points.

17.3 Construct special solutions without moving columns Lesson 31 · 12:11

Let $R=\operatorname{rref}(A)$ have $r$ pivots in columns $p_1<\cdots<p_r$, and let $J$ be the set of free-column indices. Row operations preserve homogeneous solutions, so $N(A)=N(R)$. Each nonzero reduced row says

$$x_{p_i}=-\sum_{j\in J}R_{ij}x_j.$$

For each free index $j$, define a special null vector $s^{(j)}$ by setting free coordinate $j$ to $1$, all other free coordinates to zero, and pivot coordinates $s^{(j)}_{p_i}=-R_{ij}$.

Proposition 17.2, proved here. Every null vector has the unique expression

$$x=\sum_{j\in J}x_j s^{(j)}.$$

Each special vector satisfies every reduced row by its construction, and zero rows impose no condition. Thus it belongs to $N(A)$. For a general $x\in N(A)$, the displayed sum has free coordinate $j$ equal to $x_j$. Its pivot coordinate $p_i$ is $-\sum_{j\in J}R_{ij}x_j$, exactly the value forced for $x_{p_i}$. Equality of every coordinate proves the formula. Conversely every such combination is a null vector by closure. Finally the coefficient of $s^{(j)}$ is recovered from free coordinate $j$, so no other coefficient list represents the same vector. ∎

No special vector is redundant: a combination of the others has zero in its distinguished free coordinate and therefore cannot equal it. A list with unique representations of every vector in its span will be called a basis in Chapter 19. Here uniqueness is already established concretely. If there are no free columns, the sum is empty and $N(A)=\{0\}$, consistent with the square-system theorem.

For instance, if

$$R=\begin{pmatrix}0&1&2&0&-1\\0&0&0&1&3\\0&0&0&0&0\end{pmatrix},$$

the pivot positions are $2,4$ and the free positions are $1,3,5$. The special vectors are

$$s^{(1)}=(1,0,0,0,0),\quad s^{(3)}=(0,-2,1,0,0),\quad s^{(5)}=(0,1,0,-3,1).$$

Every null vector is $(t,-2u+v,u,-3v,v)$ for unique $t,u,v\in F$. The pivot variables need not be the first $r$ variables, and no column relabeling has been hidden in this formula.

17.4 Rank counts pivots, not written equations Lesson 31 · 27:08

Define the rank $r(A)$ of a matrix to be the number of nonzero rows, equivalently pivots, in its RREF. This is well defined because Theorem 15.3 proves that reduced matrix unique. We have $0\le r(A)\le\min(m,n)$.

The special-null-vector construction gives $n-r(A)$ unique free coefficients. It also cannot be replaced by a shorter arbitrary generating list. Here is a proof without assuming a dimension theorem. Let $d=n-r(A)$, and suppose $k<d$ null vectors generated all of $N(A)$. Project onto its $d$ free coordinates. This projection maps $N(A)$ onto $F^d$, so the projected $k$ vectors would span $F^d$. Put them in columns of a $d\times k$ matrix $V$. The homogeneous system $V^{\mathsf T}y=0$ has $k$ equations in $d$ unknowns, so Chapter 15 gives a nonzero solution $y$. Choose an index $i$ with $y_i\ne0$. Since $V$ supposedly spans $F^d$, some $c$ satisfies $Vc=e_i$. But $y_i=y^{\mathsf T}e_i=y^{\mathsf T}Vc=0$, a contradiction. Thus at least $d$ generators are required; when $d=0$ this lower bound is immediate.

The word “dimension” will package exactly this invariant number once the general basis theorem is proved. We have already obtained its operational content for a null space, using only elimination and the coefficient-field laws.

17.5 What rows and columns each tell us Lesson 31 · 29:37

The column space is $C(A)=\{Ax:x\in F^n\}\subseteq F^m$. By the column picture, it equals the span of the columns of $A$. Thus $Ax=b$ is consistent exactly when $b\in C(A)$. The row space is the span of its rows, a subset of $F^n$. Both are coordinate subspaces by the span argument.

Row operations preserve the row space, as established in the RREF uniqueness proof. The nonzero reduced rows generate it without redundancy: their coefficients are read at the pivot columns, so a zero combination forces all those coefficients zero.

Columns behave differently. If $R=PA$ with $P$ invertible, then $C(R)=P(C(A))$, not necessarily $C(A)$ itself. Nevertheless the pivot columns of the original $A$ generate $C(A)$ without redundancy. Indeed the corresponding columns of $R$ are $e_1,\ldots,e_r$ in $F^m$. Every other column $R_{:,j}$ equals $\sum_{i=1}^rR_{ij}e_i$, since its bottom rows are zero. Apply $P^{-1}$ to obtain

$$A_{:,j}=\sum_{i=1}^rR_{ij}A_{:,p_i}.$$

A zero combination of those original pivot columns would become a zero combination of the distinct $e_i$ after applying $P$, forcing each coefficient zero. Thus exactly $r$ independent column choices generate the permitted right-hand sides. Later the formal dimension theorem identifies both row and column dimensions with rank.

For a concrete warning, $A=\begin{pmatrix}1&2\\1&2\end{pmatrix}$ has column space spanned by $(1,1)^{\mathsf T}$, while its RREF $\begin{pmatrix}1&2\\0&0\end{pmatrix}$ has column space spanned by $(1,0)^{\mathsf T}$. These are different subspaces. Use reduced pivot indices to select original columns, rather than returning the reduced columns as generators for the original column space.

17.6 Row annihilation and geometric language Lesson 31 · 31:36

The equation $Ax=0$ means $\sum_j a_{ij}x_j=0$ for every row $i$. It is equivalent to the same pairing vanishing against every row-space member: linear combinations preserve the zero result, and each row is itself a row-space member. Over $\mathbb R$, this is ordinary perpendicularity to the row space. Over general fields the safe statement is annihilation under the displayed bilinear pairing.

In particular over $\mathbb C$ this pairing is not a Hermitian inner product. For the row $(1,i)$, $x=(-i,1)^{\mathsf T}$ satisfies $Ax=-i+i=0$, while the pairing that conjugates the row gives $-i-i=-2i\ne0$. Conflating these two products would change the null space. Geometry remains useful when its underlying algebra is specified.

A nontrivial homogeneous solution also means a nontrivial relation among columns, $\sum_jx_jA_{:,j}=0$ with not all $x_j=0$. If $x_k\ne0$, solve this equality for $A_{:,k}$ as a combination of the other columns by dividing by $x_k$. Conversely such an expression supplies a nontrivial null relation. This is the mechanism behind redundant columns and the later definition of linear dependence.

17.7 Build generators from the pivot data

from itertools import product
import sympy as sp

A = sp.Matrix([[0, 1, 2, 1, 2], [0, 2, 4, 1, 1], [0, 3, 6, 2, 3]])
R, pivots = A.rref()
free = [j for j in range(A.cols) if j not in pivots]
vectors = []
for j in free:
    v = sp.zeros(A.cols, 1)
    v[j] = 1
    for i, pivot in enumerate(pivots):
        v[pivot] = -R[i, j]
    vectors.append(v)
N = sp.Matrix.hstack(*vectors)
assert A * N == sp.zeros(A.rows, len(free))
assert N[free, :] == sp.eye(len(free))
particular = sp.Matrix([0, 1, 0, 2, 0])
b = A * particular
print(pivots)
print(N)
print(b)

finite_solutions = []
for values in product(range(2), repeat=5):
    x = sp.Matrix(values)
    if all(int(t) % 2 == 0 for t in A * x - b):
        finite_solutions.append(values)
generated = {tuple(int(t) % 2 for t in particular + N * sp.Matrix(c))
             for c in product(range(2), repeat=3)}
assert generated == set(finite_solutions)
print(len(finite_solutions))
(1, 3)
Matrix([[1, 0, 0], [0, -2, 1], [0, 1, 0], [0, 0, -3], [0, 0, 1]])
Matrix([[3], [4], [7]])
8

The free-coordinate block of $N$ is an identity matrix, certifying unique parameters. The final enumeration reduces the same integer coefficients modulo two and checks every one of the $32$ possible input tuples. It verifies the entire affine-fiber formula for that finite example.

17.8 Problems with complete solutions

Problem 1. When is a solution translate a subspace?

For a consistent system $Ax=b$, prove its solution set is a coordinate subspace exactly when $b=0$.

If $b=0$, the solution set is $N(A)$ and has the three required closure properties. Conversely every coordinate subspace contains zero. If zero solves $Ax=b$, then $b=A0=0$. Thus any nonzero right-hand side with solutions gives an affine translate excluding the origin, not a subspace. Consistency prevents the empty set from entering the discussion as a purported translate.

Problem 2. Nonconsecutive free coordinates

Find special null generators for $R=\begin{pmatrix}1&2&0&-1\\0&0&1&3\end{pmatrix}$.

The pivots are in columns1 and3, so columns2 and4 are free. The equations give $x_1=-2x_2+x_4$ and $x_3=-3x_4$. Setting $(x_2,x_4)=(1,0)$ gives $(-2,1,0,0)$; setting it to $(0,1)$ gives $(1,0,-3,1)$. Every solution is their combination with coefficients $x_2,x_4$. These coefficients are unique because they occur unchanged in the free coordinates.

Problem 3. Original column space

For $A=\begin{pmatrix}1&2\\1&2\end{pmatrix}$ over $\mathbb Q$, solve $Ax=(3,3)^{\mathsf T}$ and explain why $(1,0)^{\mathsf T}$ cannot be used as a column generator for $A$.

The two equations both say $x_1+2x_2=3$, so all solutions are $(3-2t,t)$. The column space is $\{(s,s)^{\mathsf T}:s\in\mathbb Q\}$, generated by the original first column $(1,1)^{\mathsf T}$. The reduced first column $(1,0)^{\mathsf T}$ is not in that set, because its two entries differ. It belongs to the transformed column space instead.

Problem 4. A compatibility equation on the right-hand side

For $A=\begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}$, characterize all $b\in F^3$ for which $Ax=b$ is solvable.

The first two equations force $x_1=b_1,x_2=b_2$, and the third requires $b_3=b_1+b_2$. This condition is necessary and sufficient, and the solution is then unique. The row-combination vector $c=(-1,-1,1)^{\mathsf T}$ satisfies $c^{\mathsf T}A=0$, while $c^{\mathsf T}b=b_3-b_1-b_2$. A nonzero value certifies inconsistency; zero is the compatibility condition. The formulas work over every field.

Problem 5. A self-annihilating complex vector

Show the nonzero complex vector $v=(-i,1)$ has $v^{\mathsf T}v=0$. Why does this not contradict positivity of length?

The bilinear expression is $(-i)^2+1=-1+1=0$. But the squared geometric magnitude of the coordinate vector uses conjugation: $|-i|^2+|1|^2=1+1=2>0$. The first expression is not that positive norm square. Row annihilation for matrix equations uses bilinear multiplication; positivity statements use the real sum of squared complex magnitudes. They are different expressions.

Problem 6. Redundant does not mean useless

For $e_1=(1,0)$ and $e_2=(0,1)$, show each pair from $e_1,e_2,e_1+e_2$ spans $F^2$, but the three-member list has a nontrivial zero relation.

The relation is $e_1+e_2-(e_1+e_2)=0$, with coefficients $(1,1,-1)$ not all zero. The first two vectors generate every coordinate pair. From $e_1$ and $e_1+e_2$, recover $e_2$ by subtraction; from $e_2$ and $e_1+e_2$, recover $e_1$ similarly. Hence every pair spans the same set. Redundancy concerns retaining all generators at once, not whether an individual vector can be useful in a smaller list.
