Algebra laboratory

Use finite experiments to inspect a theorem's mechanism. Each chapter contains one executable Python listing with its checked output. This page connects those experiments and offers an offline explorer for Jordan-chain lengths.

From chains to kernel dimensions

Enter the sizes of Jordan blocks for one eigenvalue. For a size-$s$ block, applying $T-\lambda I$ repeatedly kills one more coordinate at each step. The kernel of its $k$th power has dimension $\min(k,s)$. Adding these contributions across blocks produces the nullity sequence proved in Chapter25.

Each displayed arrow points toward the vector obtained after applying $T-\lambda I$ once. The leftmost chain vector maps to zero. Changing these sizes changes the operator's block structure; changing the particular chain basis within a fixed structure does not change the table.

Run the exact chapter experiments

Use Python3 with the dependencies in requirements.txt. The early chapters rely chiefly on the standard library; later listings use SymPy for exact symbolic and rational arithmetic. Copy a listing into a file or run all chapter listings with python tools/check_chapter_code.py from the repository root. The checker compares the executed output with the printed output and records the manuscript hash.

Four variations worth predicting first

  1. In Chapter20 change the prime field for differentiation. Predict which monomials enter the kernel when the characteristic divides their exponent.
  2. In Chapter21 reverse the direction of a basis conversion deliberately. Identify the mismatched coordinate spaces before running the equality check.
  3. In Chapter23 choose a vector inside one eigenspace. Compare its cyclic polynomial with the full operator's minimal polynomial.
  4. In the explorer, compare block lists 2,2 and 2,1,1. Both have largest block two and total dimension four, but their first kernel dimensions differ.

The browser explorer uses exact integer counting and performs no network requests. The Python laboratories are separate from the browser; the site does not execute arbitrary Python or accept uploaded code.
