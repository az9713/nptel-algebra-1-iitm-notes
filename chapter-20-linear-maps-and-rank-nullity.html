20. Linear maps and rank–nullity

A linear map preserves every finite linear combination. Its kernel records the distinctions it erases, and its range records the outputs it can produce. Rank–nullity states an exact balance: in a finite-dimensional input space, the number of erased directions plus the number of surviving directions equals the original dimension.

Lessons 36–37 supply the definition, basis prescription, operator algebra, kernels, ranges, and rank–nullity. We complete the omitted linearity checks and inverse proof, correct caption slips in matrix dimensions, and state the characteristic assumption needed for differentiation examples.

20.1 Preserve combinations, not just straight lines Lesson 36 · 01:25

For vector spaces $V,W$ over the same field $F$, a map $T:V\to W$ is linear when $T(u+v)=Tu+Tv$ and $T(av)=aTv$ for all vectors and all $a\in F$. Write $\mathcal L(V,W)$ for the set of these maps, and $\mathcal L(V)=\mathcal L(V,V)$ for linear operators.

By induction, linearity gives $T(\sum_{j=1}^r a_jv_j)=\sum_{j=1}^r a_jTv_j$. The base case of an empty sum follows from $T0=T(0+0)=T0+T0$, hence $T0=0$ by cancellation. Induction adds one summand using additivity and scaling. In particular $T(-v)=-Tv$ and $T(u-v)=Tu-Tv$.

On $\mathbb R$, $f(x)=mx+b$ is linear in this sense exactly when $b=0$. Necessity follows by evaluating at zero; sufficiency follows by distributing multiplication by $m$. An offset describes an affine map. Mapping zero to zero is necessary but insufficient: $x\mapsto x^2$ on $\mathbb R$ fixes zero but fails additivity since $2^2\ne1^2+1^2$.

The zero map and identity map are linear directly from the axioms. For $A\in M_{m,n}(F)$, multiplication $T_A:F^n\to F^m$, $x\mapsto Ax$, is linear by matrix distributivity and scalar compatibility. There are $n$ input coordinates and $m$ output coordinates; the matrix shape fixes this direction.

20.2 Functions and sequences as inputs Lesson 36 · 07:13

On formal polynomials define $D(\sum a_jX^j)=\sum_{j\ge1}ja_jX^{j-1}$. Coefficientwise addition and scaling commute with this formula, so $D$ is linear over every field. On $\mathbb R[X]$ it is ordinary differentiation. Multiplication $Mp=Xp$ is linear because $X(p+q)=Xp+Xq$ and $X(ap)=aXp$.

Over $\mathbb R$, define $J(\sum_{j=0}^d a_jX^j)=\sum_{j=0}^d a_j/(j+1)$. This is a linear functional, and elementary integration identifies it with $\int_0^1p(x)\,dx$. The coefficient formula proves linearity without any additional integration theorem. A derivative is an operator on polynomials or smooth functions; it is not an operator on the space of merely differentiable functions, since a first derivative need not itself be differentiable.

On all sequences $F^{\mathbb N}$, define the left shift $L(x_1,x_2,\ldots)=(x_2,x_3,\ldots)$ and right shift $R(x_1,x_2,\ldots)=(0,x_1,x_2,\ldots)$. At each coordinate, shifting a sum gives the sum of the shifted coordinates, and shifting a scalar multiple gives that scalar times the shifted coordinate. Thus both are linear. No convergence assumption is required.

20.3 A basis lets us prescribe a map Lesson 36 · 13:49

Theorem 20.1, proved here. Given a finite basis $v_1,\ldots,v_n$ of $V$ and arbitrary $w_1,\ldots,w_n\in W$, exactly one linear map satisfies $Tv_j=w_j$ for all $j$.

Define $T(\sum a_jv_j)=\sum a_jw_j$. Unique basis coordinates ensure that this assigns one output to each input. If $u=\sum a_jv_j$ and $v=\sum b_jv_j$, then $u+v$ has coordinates $a_j+b_j$, so $T(u+v)=\sum(a_j+b_j)w_j=Tu+Tv$. Similarly $cu$ has coordinates $ca_j$, yielding $T(cu)=cTu$. The formula sends each $v_j$ to $w_j$. Conversely any linear map with those basis values must obey that formula on every vector, proving uniqueness. For $V=\{0\}$ the empty prescription yields the unique zero map. ∎

The target vectors need not be independent or distinct, and $W$ need not be finite-dimensional. Freedom on a basis does not mean freedom on an arbitrary list: any relation among prescribed input vectors must also hold among their proposed images.

20.4 Linear maps form a vector space and compose Lesson 36 · 21:33

Define $(S+T)v=Sv+Tv$ and $(aT)v=a(Tv)$. For example, $(S+T)(cu+dv)=c(Su+Tu)+d(Sv+Tv)$ by linearity and commutativity in $W$, proving closure under addition; the same calculation with $aT$ proves scalar closure. The zero map is present, so $\mathcal L(V,W)$ is a subspace of the pointwise function space $W^V$ from Chapter 18. It inherits every vector-space axiom, with inverse $(-T)v=-Tv$.

If $T:U\to V$ and $S:V\to W$, write $ST=S\circ T$. Then $ST(cu+dv)=S(cTu+dTv)=cSTu+dSTv$, so composition is linear. Associativity follows by evaluation: both $(QS)Tu$ and $Q(ST)u$ equal $Q(S(Tu))$. Identities satisfy $I_WT=T=TI_U$ for $T:U\to W$. Both distributive laws follow by evaluation and the linearity of the outer map; for example $S(T_1+T_2)u=ST_1u+ST_2u$.

Order still matters. On $F[X]$, compare $DM$ and $MD$ on a monomial: $DM(X^j)=(j+1)X^j$ while $MD(X^j)=jX^j$. Therefore $(DM-MD)p=p$ for every polynomial, by linearity. Since the constant polynomial $1$ is nonzero, $DM\ne MD$ over every field. This algebraic identity avoids any appeal to a product rule and will also help distinguish finite and infinite dimensionality.

20.5 The kernel controls every nonempty fiber Lesson 37 · 00:55

The kernel or null space is $\ker T=\{v\in V:Tv=0\}$. The range or image is $\operatorname{im}T=\{Tv:v\in V\}\subseteq W$.

Both are subspaces. The kernel contains zero; if $Tu=Tv=0$, then $T(au+bv)=0$. The image contains $T0=0$; if $y=Tu,z=Tv$, then $ay+bz=T(au+bv)$ lies in the image. These checks establish the subspace test, including nonemptiness.

Proposition 20.2, proved here. If $Tv_0=y$, then $T^{-1}(\{y\})=v_0+\ker T$. Further, $T$ is injective exactly when $\ker T=\{0\}$.

The equation $Tv=y=Tv_0$ is equivalent to $T(v-v_0)=0$, equivalently $v-v_0\in\ker T$, which proves both inclusions of the fiber identity. If $T$ is injective, only zero can have the same image as zero. Conversely, a trivial kernel and $Tu=Tv$ give $u-v\in\ker T$, so $u=v$. ∎

The notation $T^{-1}(\{y\})$ means a preimage set and does not assume an inverse function. If $y$ is absent from the range, the fiber is empty. Surjectivity means precisely $\operatorname{im}T=W$ and depends on the selected target. The derivative $P_3(\mathbb R)\to P_3(\mathbb R)$ is not onto, whereas the same rule into $P_2(\mathbb R)$ is onto.

20.6 A basis adapted to what is erased Lesson 37 · 10:45

Theorem 20.3, rank–nullity, proved here. If $V$ is finite-dimensional and $T:V\to W$ is linear, then the range is finite-dimensional and

$$\dim V=\dim\ker T+\dim\operatorname{im}T.$$

The two dimensions on the right are the nullity and rank of $T$.

Choose a basis $k_1,\ldots,k_r$ of the kernel and extend it to a basis $k_1,\ldots,k_r,u_1,\ldots,u_s$ of $V$, using Chapter 19. Applying $T$ to a basis expansion kills its first block and gives $Tv=\sum b_jTu_j$. Thus $Tu_1,\ldots,Tu_s$ spans the range, proving finite-dimensionality even when $W$ itself is infinite-dimensional.

If $\sum c_jTu_j=0$, then $\sum c_ju_j\in\ker T$. Write it as $\sum d_ik_i$ and subtract. This is a zero relation on the full basis of $V$, so all $c_j,d_i$ vanish. The image list is therefore independent and a basis of the range. Hence $\dim V=r+s$, while kernel and range have dimensions $r,s$. Empty blocks also satisfy the argument. ∎

The complement $C=\operatorname{span}(u_1,\ldots,u_s)$ satisfies $V=\ker T\oplus C$. The restriction $T|_C$ is a bijection onto the range: it is onto by the displayed image expansion, and its kernel is $C\cap\ker T=\{0\}$. Thus the theorem pairs a complement's directions with independent output directions; it does not assert that each original coordinate axis is individually either erased or preserved.

20.7 Dimension obstructions and invertibility Lesson 37 · 18:46

Suppose both spaces are finite-dimensional, with $n=\dim V$ and $m=\dim W$. Rank–nullity and the subspace inequality give

$$0\le\operatorname{rank}T\le\min(n,m),\qquad \operatorname{nullity}T=n-\operatorname{rank}T\ge\max(0,n-m).$$

If $T$ is injective, nullity is zero, so rank is $n$ and $n\le m$. If it is surjective, rank is $m$, so $m\le n$. When $n=m$, injectivity is equivalent to surjectivity: rank $n$ means the image is a full-dimensional subspace of $W$, hence equals $W$; surjectivity gives nullity zero in the reverse direction.

A bijective linear map has a linear inverse. If $x=T^{-1}y$ and $z=T^{-1}w$, then $T(ax+bz)=ay+bw$. Uniqueness of the preimage gives $T^{-1}(ay+bw)=aT^{-1}y+bT^{-1}w$. Thus a linear bijection preserves the full vector-space structure in both directions.

Finite-dimensionality is essential. For the shifts on $F^{\mathbb N}$, $LR=I$ while $RL(x_1,x_2,\ldots)=(0,x_2,\ldots)$. The left shift is onto, with nonzero kernel $Fe_1$, and the right shift is injective, with range the sequences whose first coordinate is zero. Neither is bijective. No finite dimension equation was available to force the other property.

20.8 Reconnect rank with elimination Lesson 37 · 25:08

For $T_A:F^n\to F^m$, the kernel is the homogeneous solution space $Ax=0$. Since $Ax=\sum x_jA_j$ where $A_j$ are the columns, the image is the column space. Chapter 17 proved that original pivot columns form an independent spanning list for that space. Their number $r$ is therefore its dimension, so elimination rank and map rank coincide. Rank–nullity now identifies the number $n-r$ of free parameters with $\dim\ker T_A$.

For real differentiation $D:P_d(\mathbb R)\to P_d(\mathbb R)$, the kernel consists of constants, since $ja_j=0$ implies $a_j=0$ for every $j\ge1$. If $d\ge1$, every polynomial of degree at most $d-1$ has an antiderivative obtained by dividing its coefficient of $X^j$ by $j+1$, so rank is $d$ and nullity one. For $d=0$, the range is zero and rank is zero. Over characteristic $p$, $D(X^p)=0$ although $X^p$ is not constant; the unrestricted source assertion must be qualified.

20.9 The same derivative in different fields

In the monomial basis of $P_5$, the derivative has entries $j$ in row $j-1$, column $j$. Distinct nonzero columns occupy distinct coordinate directions, so its rank is the number of coefficients $j$ that remain nonzero in the field. The code checks the prime-field cases by exhaustive kernel enumeration as well as this structural count.

from itertools import product

degree = 5
print("Q:", degree, 1)
for prime in (2, 3, 5, 7):
    rank = sum(j % prime != 0 for j in range(1, degree + 1))
    nullity = degree + 1 - rank
    kernel_size = sum(
        all(j * coefficients[j] % prime == 0
            for j in range(1, degree + 1))
        for coefficients in product(range(prime), repeat=degree + 1)
    )
    assert kernel_size == prime ** nullity
    print(prime, rank, nullity, kernel_size)

3 4 2 9
5 4 2 25

20.10 Problems with complete solutions

Problem 1. Additivity does not fix the scalar field

Show that complex conjugation on $\mathbb C$ is real-linear but not complex-linear.

Conjugation preserves addition, and for real $a$, $\overline{az}=a\overline z$, so both real-linearity requirements hold. But $\overline{i\cdot1}=-i$ whereas $i\overline1=i$, and these differ. Thus complex homogeneity fails. The domain and target must be considered over the same specified scalar field.

Problem 2. Prescribe values consistently

Can a real-linear map send $e_1,e_2,e_1+e_2$ respectively to $1,2,4$? What if the last value is $3$?

Linearity forces $T(e_1+e_2)=Te_1+Te_2=3$, so the first prescription is impossible. The corrected prescription is realized uniquely by $T(x,y)=x+2y$, because $e_1,e_2$ is a basis. The dependent third input supplies a consistency requirement, not an additional free choice.

Problem 3. A full fiber

For $T:F^3\to F^2$, $T(x,y,z)=(x+y,y+z)$, find kernel, range, and every preimage of $(a,b)$.

Solving $x+y=0$, $y+z=0$ gives $\ker T=F(-1,1,-1)$. The vector $(a,0,b)$ maps to $(a,b)$, so the range is all $F^2$. Every preimage is $(a,0,b)+t(-1,1,-1)=(a-t,t,b-t)$. The displayed generator is nonzero because its middle coordinate is one. Thus nullity is one and rank two, summing to three over every field.

Problem 4. A characteristic-two derivative

Compute the kernel and range of $D:P_5(\mathbb F_2)\to P_5(\mathbb F_2)$.

For $p=\sum_{j=0}^5a_jX^j$, we have $Dp=a_1+a_3X^2+a_5X^4$ because even integers vanish in $\mathbb F_2$ and odd integers equal one. The kernel has basis $1,X^2,X^4$, and the range also has basis $1,X^2,X^4$, each by coefficient comparison. Rank and nullity are both three, giving total dimension six. Equal kernel and range here does not mean either is the whole space.

Problem 5. Preserving independence

Prove that $T$ is injective if and only if it sends every finite independent list to an independent list.

If $T$ is injective and $\sum a_jTv_j=0$, then $T(\sum a_jv_j)=0$ implies $\sum a_jv_j=0$; input independence gives all coefficients zero. Conversely every nonzero $v$ is a singleton independent list. Its image must remain a nonzero singleton, so no nonzero vector lies in the kernel. The kernel criterion gives injectivity. If the domain is zero, both properties hold vacuously.

Problem 6. A composition bound

For finite-dimensional $U,V,W$ and linear $T:U\to V$, $S:V\to W$, prove $\operatorname{rank}(ST)\le\min(\operatorname{rank}S,\operatorname{rank}T)$.

The range of $ST$ is contained in the range of $S$, proving the first inequality by the subspace dimension theorem. Restrict $S$ to the subspace $\operatorname{im}T$. Its range is exactly $\operatorname{im}(ST)$, and rank–nullity for that restriction gives its rank at most $\dim\operatorname{im}T$. This proves the second inequality. Neither inequality requires injectivity of either map.
