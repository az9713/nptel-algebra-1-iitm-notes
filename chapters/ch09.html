9. Cardinality and the limits of enumeration

A hotel with rooms numbered by positive integers can make room for one more guest by moving guest $n$ to room $n+1$. A finite hotel cannot. But even infinitely many numbered rooms cannot accommodate every subset of the room numbers: any proposed allocation misses a subset constructed to disagree with its own assigned room. These two mechanisms distinguish finite size, countable infinity, and larger infinities.

Lesson 19 develops finite cardinality, the pigeonhole principle, infinite subsets, countability, and Cantor's theorem. We supply the omitted finite and enumeration proofs. For statements involving arbitrary families of sets, this chapter explicitly assumes the axiom of choice as a sufficient background principle; no claim about the weakest necessary choice principle is made.

9.1 Counting means a bijection Lesson 19 · 01:30

For $n\in\mathbb N_0$, write $[n]=\{1,\ldots,n\}$ when $n>0$ and $[0]=\varnothing$. A set $A$ is finite if it admits a bijection with some $[n]$; otherwise it is infinite. Once we prove the value $n$ unique, write $|A|=n$ and call it the cardinality of $A$. For arbitrary sets, $|A|=|B|$ means that a bijection $A\to B$ exists; we need not construct cardinal numbers as separate set-theoretic objects.

Proposition 9.1, pigeonhole principle, proved here. An injection $[m]\to[n]$ implies $m\le n$.

Induct on $n$. Into $[0]$ a function exists only from the empty set, so $m=0$. Suppose the result holds for $n$, and let $f:[m]\to[n+1]$ be injective. If $m=0$ there is nothing to prove. Otherwise let $y=f(m)$. Interchange $y$ and $n+1$ in the target, fixing all other points; this is a bijection, including when the two points coincide. After this interchange the image of $m$ is $n+1$, so none of the first $m-1$ inputs maps there by injectivity. Restriction gives an injection $[m-1]\to[n]$. Hence $m-1\le n$ and $m\le n+1$. ∎

If $A$ is bijective to both $[m]$ and $[n]$, composition gives a bijection between the segments. Applying the proposition to it and its inverse gives $m\le n\le m$, so $m=n$. Finite cardinality is therefore well defined.

Every subset of a finite set is finite. To prove this, it suffices to consider $B\subseteq[n]$ and induct on $n$. The empty case is immediate. If $n+1\notin B$, apply the induction hypothesis inside $[n]$. Otherwise enumerate $B\setminus\{n+1\}$ by $[r]$ using that hypothesis, and extend the bijection by sending $r+1$ to $n+1$. Thus $B$ is finite in either case. It follows that any set containing an infinite subset is infinite, by contraposition.

For a finite set of size $n$, an injective self-map is surjective. If it missed one point, composing with a relabeling of the remaining $n-1$ target points would give an injection $[n]\to[n-1]$, contradicting the proposition. Conversely a surjective self-map is injective: if two inputs agree in value, removing one leaves a surjection from $n-1$ points onto $n$ points, which would require at least one distinct input for each target, an injection $[n]\to[n-1]$. The finite choices here involve only a finite number of nonempty fibers.

9.2 Infinite sets and finite deletion Lesson 19 · 10:19

Proposition 9.2, proved here. $\mathbb N$ is infinite. Removing finitely many elements from an infinite set leaves an infinite set.

A finite nonempty list of positive integers has a maximum: start at its first value and successively retain the larger of the current maximum and the next value. Induction proves that the final value is at least every entry. Thus any map $[n]\to\mathbb N$ with $n>0$ misses one more than its image maximum, so is not onto. For $n=0$, the image is empty and also not onto. Hence no finite segment is bijective to $\mathbb N$.

If $S\setminus\{s\}$ were finite, extend its finite enumeration by the final new element $s$; then $S$ would be finite too. Therefore deletion of one element from an infinite set leaves it infinite. Induction applies this argument to a finite list of elements being removed. Deleting an element already absent changes nothing, so repetitions in the list cause no problem. ∎

In particular an infinite set has a proper infinite subset: choose one element $s$ and remove it. This single selection from a nonempty set does not require a general choice axiom. The next result requires a coherent infinite sequence of selections, a separate matter.

9.3 A proper subset can have the same size Lesson 19 · 19:54

Proposition 9.3, proved here assuming choice. Every infinite set $S$ contains a sequence $s_1,s_2,\ldots$ of distinct members, and admits a bijection onto the proper subset $S\setminus\{s_1\}$.

By the axiom of choice, fix a function $c$ selecting one element $c(A)\in A$ for each nonempty subset $A\subseteq S$. Define $s_1=c(S)$ and $s_{n+1}=c(S\setminus\{s_1,\ldots,s_n\})$. Finite deletion leaves a nonempty set, so the rule is always defined on the histories that arise. To apply the total-rule formulation of Chapter 7, assign any fixed member of $S$ when a hypothetical history exhausts $S$; no finite history actually does. The resulting sequence has distinct entries by construction.

Let $C=\{s_n:n\in\mathbb N\}$. Define $h(s_n)=s_{n+1}$ on $C$ and $h(x)=x$ on $S\setminus C$. Distinct indices determine distinct entries, so the first clause is well defined and injective, with image $C\setminus\{s_1\}$. The second clause is bijective on $S\setminus C$. These two images are disjoint and together equal $S\setminus\{s_1\}$; hence $h$ is bijective. ∎

A set bijective to a proper subset is called Dedekind-infinite. Such a set cannot be finite by the pigeonhole principle. Under the stated choice background, Proposition 9.3 gives the converse. We do not silently substitute repeated arbitrary selection for a specified recursion rule: the choice function supplies that rule. For a subset of $\mathbb N$, least elements provide a rule without this extra assumption.

9.4 Lists with repetitions can be repaired Lesson 19 · 41:16

A set is countably infinite if it is bijective to $\mathbb N$, countable if it is finite or countably infinite, and uncountable otherwise. A listing with repetitions is a surjection $f:\mathbb N\to S$; it need not be a bijection.

Lemma 9.4, proved here. Every infinite subset $A\subseteq\mathbb N$ admits a strictly increasing bijection $a:\mathbb N\to A$.

Let $a_1$ be the least member of $A$ and, after selecting $a_1,\ldots,a_n$, let $a_{n+1}$ be the least member of the remainder. Well-ordering and finite deletion justify each value; make the rule total on irrelevant histories as above. Every unselected element is greater than the selected minimum, so the sequence is strictly increasing and injective. It is onto: if $b\in A$ were never selected, every $a_n$ would be at most $b$, since $b$ remains a candidate at every step. Then $a_1,\ldots,a_{b+1}$ would be $b+1$ distinct elements of $[b]$, contradicting pigeonhole. ∎

Proposition 9.5, proved here. A nonempty set $S$ is countable if and only if there is a surjection $\mathbb N\to S$. Equivalently, an arbitrary set is countable if and only if it admits an injection into $\mathbb N$.

A countably infinite set already has a bijective listing. If $S$ has positive finite size $r$, list its $r$ distinct members first and repeat the first member forever afterward. This is onto. Conversely, given an onto $f:\mathbb N\to S$, define $j(s)$ to be the least index with $f(j(s))=s$. Every fiber is nonempty, so well-ordering gives this unique index. If $j(s)=j(t)$, applying $f$ gives $s=t$, so $j$ is injective.

For any injection $j:S\to\mathbb N$, restriction makes $j$ a bijection onto its image $A$. If $A$ is finite, $S$ is finite. If $A$ is infinite, Lemma 9.4 makes it bijective to $\mathbb N$, so $S$ is countably infinite. This proves both the converse and the injection criterion. The empty set injects into $\mathbb N$ and is finite, but has no surjection onto it from the nonempty set $\mathbb N$; that explains the nonempty qualification in the first statement. ∎

The first-occurrence rule is a canonical selection from each fiber because indices are well ordered. An arbitrary surjection between arbitrary sets has no such specified order on its fibers; the distinctions about choice in Chapter 4 remain relevant.

9.5 Count the grid, then count a union Lesson 19 · 53:51

Enumerate $(i,j)\in\mathbb N^2$ by diagonals of constant $i+j$, ordering each diagonal as $(d,1),(d-1,2),\ldots,(1,d)$ with $d=i+j-1$. There are $1+2+\cdots+(d-1)=d(d-1)/2$ entries before this diagonal. Thus the explicit index is

$$\pi(i,j)=\frac{(i+j-2)(i+j-1)}2+j.$$

The triangular-prefix formula follows by induction: adding $d$ to $d(d-1)/2$ gives $d(d+1)/2$. Consecutive diagonal index intervals are adjacent, start with $1$, and grow without bound because the $d$th endpoint is at least $d$. Each positive integer therefore lies in exactly one interval, by choosing its first bounding endpoint; its offset $j$ uniquely determines $i=d+1-j$. Thus $\pi$ is a bijection, not merely an injection.

Proposition 9.6, proved here with specified listings, or with choice to select them. A countable union of countable sets is countable.

Let the family be $(T_s)_{s\in I}$ for countable $I$. Remove empty members by replacing $I$ with $J=\{s\in I:T_s\ne\varnothing\}$. A subset of a countable set is countable by restricting an injection into $\mathbb N$ and using Proposition 9.5. If $J$ is empty the union is empty. Otherwise choose a surjection $e:\mathbb N\to J$. For each $s\in J$, fix a surjection $g_s:\mathbb N\to T_s$; these may be given as data, or chosen using the axiom of choice. Define $H(i,j)=g_{e(i)}(j)$. Every element of the union lies in some $T_s$, and choosing indices that hit $s$ and then that element shows $H$ onto. Composing $H$ with the inverse of $\pi$ gives an onto listing from $\mathbb N$, so Proposition 9.5 proves countability. ∎

For familiar sets the listings can be explicit. The integers are listed by $0,1,-1,2,-2,\ldots$: set $z(1)=0$, $z(2n)=n$, and $z(2n+1)=-n$ for $n\ge1$. Every positive integer is even or odd: this follows by induction, since adding one exchanges the forms $2r$ and $2r+1$. The formulas therefore define a bijection. The rational numbers are the image of the countable grid under $(i,j)\mapsto z(i)/j$, since every rational has an integer numerator and positive denominator. This gives a surjection with repetitions such as $1/2=2/4$; Proposition 9.5 removes repetitions in principle. The formal construction of rational arithmetic will appear in Chapter 12.

9.6 A subset missing from every proposed list Lesson 19 · 34:53

Theorem 9.7, Cantor's theorem, proved here. For every set $S$, no function $f:S\to\mathcal P(S)$ is surjective.

Given $f$, form $D=\{s\in S:s\notin f(s)\}$ by separation. If $f(a)=D$ for some $a\in S$, then $a\in D$ would mean $a\notin f(a)=D$, while $a\notin D$ would mean $a\in f(a)=D$. Both alternatives contradict themselves. Hence $D\subseteq S$ is absent from the image, so $f$ is not onto. For empty $S$, $D=\varnothing$ is still an element of $\mathcal P(S)$ absent from the empty image. ∎

Define $|A|<|B|$ to mean that an injection $A\to B$ exists but no bijection does. The singleton map $s\mapsto\{s\}$ is injective into $\mathcal P(S)$, and Cantor's theorem excludes a bijection. Thus $|S|<|\mathcal P(S)|$. Applying this repeatedly gives successively larger sizes starting from $\mathbb N$. In particular $\mathcal P(\mathbb N)$ is uncountable: it contains the infinite singleton image of $\mathbb N$, and it cannot be bijective to $\mathbb N$.

The method is called diagonalization: view the membership values $s\in f(t)$ as a table with row $t$ and column $s$. The constructed set reverses the entry on the matching row and column, so it disagrees with every row somewhere. Unlike unrestricted comprehension in Russell's paradox, $D$ is safely bounded inside the existing set $S$. The contradiction concerns the assumed completeness of the list, not the existence of $D$.

9.7 Exhaust the finite diagonal argument

For a three-element set, a subset is represented by a three-bit integer. There are eight subsets and $8^3$ possible proposed three-row lists. The program builds the diagonal subset for every list and confirms that it is never among the rows.

from itertools import product

size = 3
checked = 0
for rows in product(range(2 ** size), repeat=size):
    diagonal = sum(1 << i for i in range(size)
                   if not (rows[i] & (1 << i)))
    assert diagonal not in rows
    checked += 1
print(checked)


def index(i, j):
    return (i + j - 2) * (i + j - 1) // 2 + j


first = [(d + 1 - j, j) for d in range(1, 5)
         for j in range(1, d + 1)]
assert [index(i, j) for i, j in first] == list(range(1, 11))
print(first)
512
[(1, 1), (2, 1), (1, 2), (3, 1), (2, 2), (1, 3), (4, 1), (3, 2), (2, 3), (1, 4)]

The experiment checks all $512$ lists in this finite model. The proof above works for every set, including those with no grid of integer indices. Finite exhaustive checking is useful corroboration but cannot establish the infinite theorem by itself.

9.8 Problems with complete solutions

Problem 1. A finite bijection and a missed point

Let $A$ have $n$ elements and $f:A\to A$ be injective. Prove that no point is missed, including $n=0$.

When $n=0$, the empty map is onto the empty target. When $n>0$, suppose $a$ is missed. Removing $a$ leaves $n-1$ elements: relabel $a$ last in an enumeration of $A$ and restrict to the first $n-1$. The map $f$ would then inject an $n$-element set into an $(n-1)$-element set, contrary to Proposition 9.1. Thus it is onto. The proof identifies exactly where finite cardinality matters; the successor injection on $\mathbb N$ misses $1$.

Problem 2. First occurrences

Suppose a surjection $f:\mathbb N\to S$ has initial values $a,b,a,c,b,d$. What are the first-occurrence indices of these four symbols? Explain why the rule stays injective for the full list.

The indices are $j(a)=1$, $j(b)=2$, $j(c)=4$, and $j(d)=6$. Later repetitions cannot change a least index. If two symbols had the same first-occurrence index $r$, the single value $f(r)$ would equal both symbols, forcing them equal. Every symbol has such an index because $f$ is onto. Thus the rule defines an injection regardless of how often later values repeat.

Problem 3. Give the missing inverse of the shift

For Proposition 9.3's map $h:S\to S\setminus\{s_1\}$, write and verify its inverse.

On the chain set define $k(s_{n+1})=s_n$ for $n\ge1$; outside the chain define $k(x)=x$. These clauses cover the target because its chain elements are precisely $s_2,s_3,\ldots$. Distinctness of the sequence makes the index unique. For a chain input $s_n$, $k(h(s_n))=k(s_{n+1})=s_n$; outside the chain both maps fix the input. The corresponding target calculations give $h(k(y))=y$. Therefore $k$ is a two-sided inverse.

Problem 4. A diagonal subset by hand

Let $S=\{1,2,3\}$ and $f(1)=\{1,3\}$, $f(2)=\{1\}$, $f(3)=\{2,3\}$. Construct the missing diagonal set.

Because $1\in f(1)$, omit $1$. Because $2\notin f(2)$, include $2$. Because $3\in f(3)$, omit $3$. Thus $D=\{2\}$. It differs from $f(1)$ at $1$, from $f(2)$ at $2$, and from $f(3)$ at $3$. These three controlled disagreements, rather than a comparison of all off-diagonal entries, prove $D$ is missing.

Problem 5. Finite subsets of the natural numbers

Prove that the set of all finite subsets of $\mathbb N$ is countably infinite.

For each $r\ge1$, send an ordered tuple in $\mathbb N^r$ to its set of entries. Iterating the grid bijection shows $\mathbb N^r$ countable by induction on $r$; its image is countable by listing and Proposition 9.5. Add the empty set for $r=0$. The union over all $r\in\mathbb N_0$ is precisely the family of finite subsets, so is countable by Proposition 9.6, with explicit tuple listings available. It is infinite because distinct singletons $\{n\}$ give an injection from $\mathbb N$. Hence it is countably infinite. This does not enumerate all subsets; Cantor's theorem excludes that stronger claim.

Problem 6. Binary sequences cannot be listed

Prove that functions $\mathbb N\to\{0,1\}$ form an uncountable set.

A subset $A\subseteq\mathbb N$ corresponds to its indicator sequence $\chi_A$, with value $1$ exactly on $A$. Distinct subsets give distinct indicators, and every binary sequence gives its set of $1$ positions, so this correspondence is bijective to $\mathcal P(\mathbb N)$, which is uncountable. Directly, for any proposed sequence of rows $a_1,a_2,\ldots$, the binary sequence $b(n)=1-a_n(n)$ differs from row $n$ at position $n$. Thus no proposed listing is onto.
